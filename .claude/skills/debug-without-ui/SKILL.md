# Debugging without UI access

Debug builds: `URSPRUNG_SNAPSHOT_DIR=<dir>` writes window snapshots plus `frame.png`/`session.txt` of the running game; `URSPRUNG_AUTOPLAY=<title>` starts a game, `URSPRUNG_SELECT=<title>` selects one (`<title>|<title>` several), `URSPRUNG_SYSTEM=<id>` shows one system, `URSPRUNG_FOLDER_SETUP=1` shows the first-launch folder structure sheet, `URSPRUNG_METADATA_ERROR=<text>` shows the activity footer's error row (`quota` for the real quota copy), `URSPRUNG_CORE_LOG=1` mirrors core logs to stderr, `URSPRUNG_DEBUG_STATES=1` exercises save/load/quit (for a PS2 game in ARMSX2: waits for the first frame, saves slot 1 and loads it through PINE, then quits; check `States/<game id>/armsx2/` and ARMSX2's `Emulators/ARMSX2/Logs/last-run.log`), `URSPRUNG_SHADER_EDITOR=<preset:library/path.slangp|preset:user/path.slangp|system id|new>` opens the shader editor with that preset, `URSPRUNG_SHADER=<built-in filter raw value|preset:library/path.slangp|preset:user/path.slangp>` replaces the player's shader choice, `URSPRUNG_SHADER_PARAMS=NAME=value,NAME=value` sets parameters of every preset that loads, `URSPRUNG_DEBUG_PLAY=1` takes a screenshot, rewinds, fast forwards and quits (`session.txt` shows rewind seconds, run-ahead, cheats and patch, and `graphics=software|opengl|vulkan`). `URSPRUNG_VULKAN_LOG=1` logs the Vulkan context to stderr (negotiation, instance and device extensions, frame format, readback cost when the game unloads); `ursprung-smoke` also takes `URSMOKE_RENDERER=vulkan`, `URSMOKE_LIST_OPTIONS=1`, `URSMOKE_REPEAT=n` and `URSMOKE_SAVE_STATE`/`URSMOKE_LOAD_STATE=<file>`. Liquid Glass and Metal layers do not appear in window snapshots; with a preset showing, `URSPRUNG_SNAPSHOT_DIR` also gets the preset's output every two seconds as `shader-output.png` (player, before rotation, ambient and bezel) and `shader-editor-preview.png` (the editor's still preview), and `session.txt` adds `shader=<status> gpu=… budget=… tooSlow=… params=[first six NAME=value in panel order]`.
